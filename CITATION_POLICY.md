# Citation Policy

## Scope
This policy applies to the full connected repository suite that includes:
- `detrend_advisor.py` (primary upstream detrending/advisory app), and
- `ringclim.py` (downstream companion climate-analysis app).

Please cite the suite in publications, reports, software derivatives, and educational reuse when your work uses, adapts, extends, or redistributes this codebase.

## Recommended citation targets
1. The software repository itself (current source state and version).
2. The program paper/article when available.

Use `CITATION.cff` for machine-readable metadata.

## Program paper placeholders
If the paper metadata is not finalized yet, use the following placeholders consistently in project documents:
- TODO: article title
- TODO: journal
- TODO: year
- TODO: DOI
- TODO: author list

## Important licensing clarification
The repository is MIT-licensed. MIT terms do not themselves impose a legal obligation to cite an article. Citation is a scholarly best practice that this project strongly encourages.
