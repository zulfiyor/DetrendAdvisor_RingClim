# Security Policy

## Reporting a vulnerability
Please report suspected vulnerabilities privately through GitHub Security Advisories for this repository.

Include:
- affected file/module,
- reproduction steps,
- impact assessment,
- suggested mitigation (if known).

## Scope notes
This repository includes desktop GUI software and scientific workflows. Security review may involve:
- file import paths and parsers,
- subprocess execution (for example R/Rscript workflows),
- packaging/runtime environment assumptions.

## Response targets
Maintainers will triage reports as quickly as possible and coordinate fixes/disclosure timing based on severity and reproducibility.
