# RingClim Overview (`ringclim.py`)

## Role
Companion climate-analysis application in the connected suite; also independently runnable.

## Inputs (high-level)
- Chronology and climate datasets from text/CSV/Excel and related supported formats.
- Time-series inputs for monthly and daily/hourly-oriented analysis contexts.
- Includes import helpers and auto-detection logic for common/specialized layouts.

## Analysis workflows
- Chronology-climate correlation workflows.
- Climate-window analysis/scanning and reporting.
- Daily/hourly and monthly data handling in appropriate workflow paths.

## UI/outputs
- Data preview and exploratory plotting.
- Export of analysis tables/figures and report-like outputs.
- Batch-style import support for repeated dataset ingestion patterns.

## Suite integration
- Can be run standalone.
- Can be launched downstream from Detrend Advisor using prefill manifest handoff.
